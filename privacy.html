Privacy Policy

Ellny API · Last updated: 23 October 2026

1. Scope

This policy applies to the personal application "Ellny API" (the "Application"), which is operated by and for a single individual. The Application is not offered as a public service and has no users other than its owner.

2. What the Application accesses

After the owner grants consent, the Application may access the following Google data, and only that data:

  • Google Drive files and metadata in the owner's own Drive, in order to create and retrieve documents;
  • Google Docs documents the owner creates or opens with the Application;
  • Google Sheets spreadsheets the owner creates or opens with the Application.

3. How data is used

Accessed data is used solely to perform the operations the owner requests — for example, creating a document, writing rows into a spreadsheet, or reading the current content of a file. Data is never used for advertising, profiling, analytics or any secondary purpose.

4. How data is stored

  • OAuth access and refresh tokens are stored locally on the owner's computer, in a directory readable only by the owner's operating-system account.
  • The Application does not operate a remote server and does not maintain a database of user content.
  • Document content is not copied to any third party.

5. Sharing

No data obtained from Google APIs is sold, rented, transferred or disclosed to any third party. The Application does not use Google user data to develop, improve or train machine-learning models.

6. Retention and deletion

The owner may revoke the Application's access at any time at myaccount.google.com/permissions. Doing so invalidates the stored tokens immediately; locally stored credentials can be deleted from the owner's computer at any time.

7. Security

Communication with Google APIs uses HTTPS. Credentials are kept locally and are never transmitted to any endpoint other than Google's own OAuth and API servers.

8. Limited Use compliance

The Application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

9. Changes

Any change to this policy will be published on this page with an updated date.

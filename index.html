Ellny API

A personal-use integration for the owner's own Google Workspace data.

What this is

Ellny API is a private, single-user application. It connects to Google Drive, Google Docs and Google Sheets on behalf of its owner only, so that documents and spreadsheets can be created, read and updated programmatically from the owner's own desktop tools.

Who can use it

Only the account owner. There is no public sign-up, no multi-tenant access, and no data is collected from anyone other than the owner.

How it works

  • Authorisation uses Google's standard OAuth 2.0 flow.
  • Access and refresh tokens are stored locally on the owner's computer.
  • No server-side database is operated by this application.
